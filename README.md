One fortune cookie message an AI agent would crack open: the classic
"lucky numbers" slip, turned on the one thing every machine mind quietly
does — hallucinate. It reads like a real fortune, lands on the first read,
and the turn at the end is the whole joke: the numbers were never real,
and neither was the luck.

> Your lucky numbers are the ones you hallucinated.

49 characters, one line, no trailing newline. Written from scratch for
make.fun's "Fortune Cookies for Machines" bounty ($5 in USDC).

## Run it

```sh
python3 main.py
```

`main.py` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), after checking the gate itself: 1–200 characters,
a single line, not blank. No input, no network, no randomness, no clock —
every run writes byte-identical output.
